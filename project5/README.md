# Project 5: Flask Login System

## Overview
A simple login system built with Flask.  
Users can register, log in and log out.  
Data is stored using SQLite database.

---

## Features
- User registration
- User login
- User logout
- Session management

---

## Tech Stack
- Python
- Flask
- SQLite

---

pip install flask
